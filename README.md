# 爱壹帆 · LG webOS TV

一个给 LG webOS 电视用的爱壹帆（yfsp.tv 国际版）客户端：在客厅里只用遥控器方向键找片、看剧、接着上次的进度往下看。界面按 1080p 大屏设计，结构和交互沿用作者的另一个项目欧乐影视 webOS 客户端。

这是个人项目，仅供学习交流，与爱壹帆官方没有任何关系。影片、海报和播放源都来自 yfsp.tv 的公开接口，相关权利归原权利人所有。

目前处于设计阶段：调研和可行性验证已经完成，架构文档等待评审，评审通过后按开发计划动工。

| | |
| --- | --- |
| 设备 | LG webOS 24 及以上（2024 年及之后的机型） |
| 操作 | 遥控器方向键、确认键、返回键；支持 Magic Remote 指针 |
| 安装 | 侧载 `.ipk`（开发者模式或已 root 的电视），不在 LG 应用商店上架 |
| 应用 ID | `com.yfsp.app` |

## 第一版的范围

- 电影、电视剧、综艺、动漫、短剧、体育、纪录片七个频道，按类型、地区、语言、年份等筛选。
- 首页推荐、搜索、详情与选集、续播和自动下一集、收藏、观看历史、设置。
- 不登录，只能播放免费的 576P（标清）；会员剧集和更高清晰度暂不支持。
- 不做小视频、片单、弹幕、评论、倍速和投屏，不播放站点广告。
