# 爱壹帆网页版界面调研

调研对象是 https://www.yfsp.tv/（爱壹帆国际版），目的是给电视端界面设计找依据：站点怎么组织内容、筛选维度有哪些真实取值、卡片和详情页展示哪些字段、配色和字号大概是什么样。

调研时间 2026-10-28，未登录，出口地区被识别为美国（接口带 `region=US`），桌面视口 1600×900。截图在 `img/` 下，文末有索引。颜色和尺寸都是用浏览器读 computed style 拿到的实际值，不是目测。

## 整体框架

站点是 Angular 单页应用，深色主题，背景 `#090b21`（偏蓝的深藏青，不是纯黑）。页面骨架是顶部固定导航栏（高 62px）加内容区；只有首页额外有一条左侧竖向频道栏，其他页面把频道收进顶栏左侧的「影视 ▾」下拉。

顶栏从左到右：logo、频道下拉、搜索框（圆角胶囊）、VIP 入口（显示「VIP7.8折」之类的促销文案）、签到、客户端下载、观看历史、消息、登录。页面右侧还悬着一列快捷按钮：简繁切换、一键换肤、下载 APP、升级 VIP、帮助。

页脚有地区切换：全球 GL、美国 US、加拿大 CA、英国 UK、意大利 IT、德国 DE、法国 FR、西班牙 ES、东南亚 MY、澳洲 AU、日本 JP、新西兰 NZ、韩国 KR、新加坡 SG。接口参数里的 `region` 应该就对应这里，片库可能随地区不同（比如搜「庆余年」只出了第 2 季，没看到第 1 季，是否是地区版权导致的还没核实）。

广告非常密：首页轮播第一帧是博彩广告，列表页筛选面板右侧、播放页右栏和播放器下方都有广告位，播放前还有贴片广告。广告链接统一走 `ppt.yfsp.tv/c/c?position=...`，电视端可以按这个域名把它们过滤掉。

官方自己有安卓电视/机顶盒客户端（下载页标注 v2.4.5，「支持 4K、云加速」），从宣传图看是顶部标签栏加大图轮播的布局，和 olevod 的电视端结构接近。

## 筛选维度

列表页顶部是一块筛选面板，每一行左边是蓝底标签（「全部分类」「全部地区」…），右边是取值。选中项文字变成主色 `#00c0ff`，选中「全部」时左边标签是蓝底白字。所有选择都直接反映到 URL 上：

| 维度 | URL 参数 | 取值 |
| --- | --- | --- |
| 版块 | 路径 slug | 电影、电视剧、综艺、动漫、短剧、体育、纪录片（加小视频频道和午夜版） |
| 类型 | 路径 `-<id>` | 见上表 |
| 地区 | `region` | 大陆、香港、台湾、日本、韩国、欧美、英国、泰国、其它 |
| 语言 | `language` | 国语、粤语、英语、韩语、日语、西班牙语、法语、德语、意大利语、泰国语、其它 |
| 年份 | `year` | 今年、去年、更早、90年代、80年代、怀旧（传的就是中文字面值，不是具体年份） |
| 画质 | `bitrate` | 4K、1080P、900P、720P |
| 状态 | `status` | 全集、连载中（连载中是 `status=1`）；电影没有这一行 |
| 形式 | `isVertical` | 横屏、竖屏（竖屏是 `isVertical=1`），只有短剧有 |
| 排序 | `orderBy` | 添加时间（默认）、人气高低（2）、评分高低（3）；剧集类多一个「更新时间」，搜索页再多一个「匹配程度」 |

几个和 olevod 不一样的地方：地区和语言是两个独立维度；年份是相对区间而不是具体年份；多了画质和状态；没有片名首字母。一个完整的例子：

```
/list/movie-20?region=大陆&language=国语&year=去年&bitrate=4K&orderBy=3
```

列表页是 6 列竖版海报网格，一页 36 部，底部是传统分页（「上一页 1 2 3 … 385 下一页」），不是无限滚动。结果数显示为「共有 13850 个筛选结果」。排序栏右侧有一个「排行」入口。

## 首页

从上到下：

1. 大图轮播。7 帧左右，每帧左上是标题和「电影·喜剧」这样的副标题，带「立即播放」按钮；底部一行是轮播片名的文字索引（部分带红色数字角标，看上去是更新集数），右侧是缩略图条。第一帧是广告。
2. 今日热点：横版 16:9 卡片（420×236），内容是新闻类小视频。
3. 猜你喜欢：同样是小视频横版卡片。
4. 电影、电视剧、综艺、动漫、短剧各一排货架。货架标题 22px，标题右边紧跟几个类型快捷标签（电影是喜剧、爱情、动作、犯罪、科幻、奇幻、冒险）和「更多」。货架是两行网格，不是单行横滑。
5. 片单：专题合集卡片。
6. 华人、游戏、新闻、娱乐、生活、音乐、时尚、科技等小视频货架。

另外顶栏「历史」按钮有观看历史弹层（`/user/watch-history`），未登录也能用，应该存在本地。

电视端首页建议：保留轮播（过滤掉广告帧），后面接「继续观看」，然后是电影、电视剧、综艺、动漫、短剧五排货架，可以再加一排排行榜精选。今日热点、猜你喜欢和小视频货架都不要。

## 卡片

长视频卡片是竖版海报，网页上 236×337（比例约 0.7），圆角 6px。结构：

- 海报底部压一条渐变（`linear-gradient(transparent, rgba(0,0,0,.5) 38%, rgba(0,0,0,.9))`），渐变上右下角显示评分（`#ffa800`、16px 粗体）；剧集类在同一位置显示「更新 02」或「06集全」。
- 右上角角标：红底白字的「新」（`#ff0000`，圆角 4px，12px 字）、4K 图标（图片 `assets/images/4K.png`）。
- 左上角有「推荐」图标（`assets/images/recommender.png`）。
- 海报下方是片名（16px 白色）和类型（14px，40% 透明白）。短剧卡片类型行里会带「竖屏」。
- 鼠标悬停时卡片放大成一张详情浮层：评分、片名、类型 / 地区 / 年份 / 语言四个标签、添加日期或更新信息、主演、简介前两行、热度（火焰图标加数字，`#ff743d`）、「详情」按钮。

海报图片在 `static.yfsp.tv/upload/video/*.gif`（后缀是 gif，但带 `format=jpg` 参数时返回 jpg），支持服务端缩放：`?w=238&h=340&format=jpg&mode=stretch`，也有 `mode=crop`。电视端可以按自己的卡片尺寸直接请求合适大小，省流量和解码时间。横版图用 `w=640&h=360&mode=crop`。

## 搜索

点搜索框会弹出下拉：上面是「历史搜索」（本地，可清空），下面是「热门搜索」前 10，前三名序号是橙色斜体。热搜数据来自 `rankv21.yfsp.tv/v3/list/gethotsearchlist?cinema=1&size=10`，这个接口不带签名。

结果页路由是 `/search/<关键词>`。顶部分「视频」「用户」两个结果类型；下面是排序（匹配程度、添加时间、更新时间、人气高低、评分高低）和一整套筛选（版块、地区、语言、年份、画质、状态），右侧栏是热门搜索。结果把长视频和小视频混在一起：长视频是横排大卡（海报、标题高亮关键词、类型 / 地区 / 年份 / 语言、评分、热度、导演、主演，下面直接摊开选集按钮），小视频是一行缩略图加时长、上传时间和上传者。电视端只保留长视频结果即可。

## 排行榜

`/rank` 会跳到 `/rank/all`。顶部是一张带波纹的横幅「排行榜」，下面一排标签：全站榜、电影榜、热剧榜、综艺榜、动漫榜。

全站榜页面并排四列（电影榜、热剧榜、综艺榜、动漫榜），每列右上角可切换「周 / 月 / 年」，选中项是主色。每列 9 条：前三条带海报、类型 / 地区 / 年份 / 语言标签、热度（如「847.1万」）和大号评分，名次是橙色斜体大数字；4 到 9 名只有片名和评分。列的背景是 `rgba(102,102,102,.2)`，标签底色 `#2b2c3a`。

olevod 没有排行榜，这是需要新增的页面。

## 详情与播放（同一页）

网页没有独立的详情页，`/play/<视频id>` 既是详情页也是播放页，进入就开始播。换集是 `/play/<视频id>?id=<剧集id>`，两种 id 都是 11 位左右的短串（如 `uHcU4Clu390`、`on7Hba8mDqA`），另外接口里还能看到数字 id（如 `50365`）。

布局是左边播放器加信息区，右边广告、上传者卡片和「相关内容」。

播放器（未登录）：

- 先播贴片广告，再放正片。
- 控制栏：播放 / 暂停、下一集、时间、选集、清晰度、倍速、音量、设置、全屏；下面是点赞、点踩、收藏、分享等计数和弹幕输入框。
- 清晰度：4K（客户端）、蓝光 1080P、高清 720P、标清 576P。720P 及以上都带 VIP 标记，未登录只能看 576P，菜单上方有「去广告·享高清 / 开通VIP / 金币解锁」。我们抓到的正片实际分辨率是 864×362（576P 档的宽银幕片）。
- 倍速 0.5x、0.75x、1.0x、1.25x、1.5x、2.0x；设置里有画面比例（默认、4:3、16:9）、自动开始播放、跳过片头 / 片尾、画中画、字幕样式（默认、黑底白字、透明黄字）。
- 有弹幕，正片上方滚动显示。
- 没有「线路」或「播放源」切换，页面文本里搜不到「线路」二字。同一部片的不同语言版本是独立条目，比如「空枪」和「空枪(粤语)」、「璀璨之城(粤)」，各自有自己的 id。接口里有 `v3/video/languagesplaylist`，可能就是在关联这些语言版本，需要接口侧确认。
- 页面往下滚时播放器会缩成右下角的小窗继续播。

信息区字段：片名加当前集（「美人余 01」），「详情 / 统计」两个折叠页签，类型 / 地区 / 年份 / 语言标签（底色 `#1c1d2f`），热度（「437.0万」），站内评分（「8.1分」，`#ffa800`）。展开后是海报、集数状态（「28集全」）、添加日期、导演（有的片没有）、主演（斜杠分隔）、简介。电影还多一行「评分」，并列两个分数：站内评分和一个绿色图标的第三方评分（看上去是豆瓣，例如空枪 7.9 / 7.2）。

选集是方块按钮网格，按钮 77×52、圆角 2px、底色 `#101227`，普通态文字 40% 白，当前集文字变主色 `#00c0ff` 并带一个小柱状图标。集号是补零的字符串（「01」「0801」）。长剧集按 50 集一组分段，组标签形如「0001-0050」「0251-0302」（不严格整 50，跟着实际集号走），一排放不下时最后一个变成下拉。打开「海贼王」时默认定位到了第 0801 集而不是第 1 集，默认集的规则还不清楚。

下面是评论区（「评论区(300)」，未登录只能看），右侧「相关内容」是同名或相关的影片列表，偶尔混入片单。

字体用系统字体栈：`-apple-system, system-ui, arial, "Segoe UI", Roboto, "Hiragino Sans GB", STHeiti, "Microsoft YaHei", ...`，没有自定义正文字体，图标是 iconfont。字号偏小：货架标题 22px / 500，卡片片名 16px，类型 14px，标签和说明 12–13px，详情片名 20px 粗体。

交互态：网页只有 hover，没有为键盘焦点设计的样式。hover 卡片是放大加详情浮层；侧栏和筛选的选中态都只是文字变成主色，没有底色块。

给电视端的取舍：背景和主色直接沿用 `#090b21` / `#00c0ff`，评分用 `#ffa800`，VIP 用 `#fec1a1`，这样一眼能认出是爱壹帆。字号按 10-foot 规格放大，沿用 olevod 的 22–60px 档位。焦点态需要自己设计，网页没有可抄的；建议用主色描边加轻微放大，替换 olevod 现在的白色描边。圆角可以比网页大一些（olevod 是 14px），网页 6px 在电视上会显得生硬。

## 电视端页面清单建议

对照 olevod 的 `app/src/pages` 和 `config/taxonomy.js`：

| 页面 | 处理 | 说明 |
| --- | --- | --- |
| 顶部标签栏 TabBar | 沿用 | 标签换成 首页、电影、电视剧、综艺、动漫、短剧、体育、纪录片，加新增的「排行」；去掉 olevod 的「VIP蓝光」。搜索、收藏、历史、设置、账号图标保持不变 |
| 首页 HomePage | 沿用结构 | 轮播（过滤 `ppt.yfsp.tv` 广告帧）、继续观看、我的收藏、五个频道货架。不要小视频货架 |
| 分类页 CategoryPage + FilterPanel | 沿用，改筛选维度 | 类型仍是第一层；「额外筛选」里放地区、语言、年份区间、画质，剧集类加状态，短剧加横竖屏。去掉首字母。排序改成添加时间、更新时间（剧集类）、人气、评分。站点是分页接口，前端继续做成滚动自动加载 |
| 搜索 SearchPage | 沿用 | 屏幕键盘和拼音首字母联想照搬；热门搜索用 `gethotsearchlist`；结果只留长视频 |
| 详情 DetailPage | 沿用，加字段 | 加热度、第三方评分、语言标签、「N集全 / 更新至」。50 集分组和 olevod 现有逻辑一致，组名改用站点的「0001-0050」格式也可以。语言版本若接口能关联，做成详情页上的「国语 / 粤语」切换 |
| 播放器 | 沿用，加清晰度 | 新增清晰度选择（576P 免费，720P 以上需要 VIP，4K 网页标「客户端」专属，电视端能否拿到要看接口）。倍速、跳过片头片尾可以后续加。不做弹幕，不播贴片广告。暂时不做「线路切换」，网页上没有这个概念，除非接口返回多个源 |
| 排行榜 RankPage | 新增 | 电影 / 热剧 / 综艺 / 动漫四个榜，周 / 月 / 年切换。电视上建议一屏一个榜，左边榜单切换，右边是带名次的海报网格，而不是网页那样四列并排 |
| 收藏、历史、设置 | 沿用 | 本地存储逻辑不变 |
| 账号 AccountPage | 待定 | 网页登录可能涉及人机验证（主包里有 Turnstile 和 reCAPTCHA），能否在电视上登录要等接口调研结论；不能登录的话账号页和 VIP 相关入口先不做 |
| 片单 | 以后再说 | 站点特色，但不是核心路径，MVP 不做 |

## 顺带看到的接口

只记录 URL 形状，给接口调研参考，没有逐个验证：

- 详情：`m10.yfsp.tv/v3/video/detail?cinema=1&device=1&player=CkPlayer&tech=HLS&country=..&lang=cns&v=1&id=<视频id>&region=US&vv=<签名>&pub=<...>`
- 播放：`m10.yfsp.tv/v3/video/play?cinema=1&id=<视频id>&a=1&lang=none&usersign=1&region=US&device=1&isMasterSupport=1&v=1&vv=..&pub=..`
- 选集 / 语言版本：`m10.yfsp.tv/v3/video/languagesplaylist?cinema=1&vid=<视频id>&lsk=1&taxis=0&cid=0,1,4,132&...`
- 评分、评论、弹幕、相关：`v3/video/GetRatingList`、`v3/video/commentList`、`api/video/getBarrage`、`rankv21.yfsp.tv/api/home/getRelativeVideo`
- 热搜：`rankv21.yfsp.tv/v3/list/gethotsearchlist?cinema=1&size=10&v=1&cacheable=1`（无签名）
- 视频流：`exchange-*.pipecdn.vip/<路径>/chunklist.m3u8?vendtime=..&vhash=..`，分片 `media_N.ts?vCustomParameter=0_<客户端IP>_US_1_0_1_0&lb=..`。注意 `vCustomParameter` 里带了客户端 IP，可能和播放地址绑定

签名参数叫 `vv`，另有一个很长的 `pub` 参数，和 olevod 的 `_vv` 不完全一样。
